# STANDARD ROAST (스탠다드로스트) — 로스팅 머신 ↔ 노트북 연결

1. 노트북 **Chrome 또는 Edge**에서 `roastlog/index.html` 열기 (Safari/Firefox는 USB 연결 불가)
2. 로스팅 탭 → **USB 시리얼 연결** → 장치 선택
3. 센서가 한 줄씩 보내는 형식을 자동 인식합니다.
   - `200.5,230.1` (BT,ET) / `BT=200.5,ET=230.1` / `T1:200;T2:230` / `{"bt":200,"et":230}`
   - 채널이 반대면 설정에서 "BT/ET 채널 바꾸기", 오차는 보정(°C)으로 맞춥니다.
4. 장비 없이 먼저 써보려면 **시뮬레이터**.

자동 감지: 터닝포인트, 건조 종료(기본 BT 160°C), 1차/2차 크랙(마이크), RoR 급락·스톨·플릭 경고, 투입(BT 급락).
`arduino/roast_thermo.ino` 는 K타입 열전대 2개 → USB 시리얼 출력 예제입니다.
이미 쓰는 로거(Phidgets, Arduino, USB-TC 등)가 줄 단위 텍스트를 내보내면 그대로 연결됩니다.
