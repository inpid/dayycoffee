# TAAS — 로스팅 머신 ↔ 노트북 연결

1. 노트북 **Chrome 또는 Edge**에서 `roastlog/index.html` 열기 (Safari/Firefox는 USB 연결 불가)
2. 로스팅 탭 → **USB 시리얼 연결** → 장치 선택
3. 센서가 한 줄씩 보내는 형식을 자동 인식합니다.
   - `200.5,230.1` (BT,ET) / `BT=200.5,ET=230.1` / `T1:200;T2:230` / `{"bt":200,"et":230}`
   - 채널이 반대면 설정에서 "BT/ET 채널 바꾸기", 오차는 보정(°C)으로 맞춥니다.
4. 장비 없이 먼저 써보려면 **시뮬레이터**.

자동 감지: 터닝포인트, 건조 종료(기본 BT 160°C), 1차/2차 크랙(마이크), RoR 급락·스톨·플릭 경고, 투입(BT 급락).
`arduino/roast_thermo.ino` 는 K타입 열전대 2개 → USB 시리얼 출력 예제입니다.
이미 쓰는 로거(Phidgets, Arduino, USB-TC 등)가 줄 단위 텍스트를 내보내면 그대로 연결됩니다.

## 이지스터(Easyster) 로스터기
- Cropster 자료상 이지스터 800g~15kg 일부 모델은 **Autonics TX4S 온도조절기 + USB 포트**(SCM-US48I, FTDI 드라이버) 방식입니다. 이 방식은 줄 단위 텍스트가 아니라 **Modbus RTU** 입니다.
- 앱의 연결 설정에서 프로토콜 `Modbus RTU`를 선택하고, 기본값(보레이트 9600, 패리티 none, BT=ID1, ET=ID2, 기능코드 4, 주소 1000, ÷10)은 **Autonics 일반값 추정**입니다.
- 실제 장비와 다르면 `연결 설정 → Modbus 진단 도구 → 자동 탐색`으로 응답하는 ID/주소를 찾아 수정하세요. 화면에 보이는 현재 온도와 같은 값이 나오는 항목이 정답입니다.
- 2022년 이후 터치스크린(PLC) 모델은 USB가 아니라 네트워크(IP)로 통신할 수 있고, 이 경우 브라우저만으로는 연결할 수 없어 별도 중계 프로그램이 필요합니다.
