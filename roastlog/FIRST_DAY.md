# TAAS 첫날 체크리스트 (이지스터 연결)

## 오늘 인터넷 되는 곳에서 미리
- [ ] `roastlog/index.html` 을 노트북에 저장 (파일 하나로 인터넷 없이 동작). 이름을 `TAAS.html` 로 바꿔도 됩니다. **같은 파일만 계속 열어야** 기록이 이어집니다.
- [ ] 노트북에 **Chrome** 설치 (Edge도 가능, Safari/Firefox는 USB 연결 불가)
- [ ] Windows 노트북이면 **FTDI USB 드라이버**(VCP) 설치 파일을 미리 받아두기. 인터넷 없이 장치를 꽂으면 드라이버가 안 잡힐 수 있습니다. (Mac은 보통 기본 포함)
- [ ] **USB 케이블**(데이터 통신용) 챙기기, 노트북 충전기
- [ ] 집에서 한 번 `index.html` 열고 로스팅 탭 → **시뮬레이터**로 화면 익히기

## 매장에서 연결
1. 기계 전원 ON → 노트북과 기계의 USB 단자 연결 (장치관리자 > 포트(COM)에 새 장치가 뜨는지 확인)
2. Chrome에서 TAAS 파일 열기 → **로스팅** 탭
3. **🔎 통신 설정 자동 탐색** → 포트 선택 → 약 1분 대기 (아래 로그 창이 자동으로 열립니다)
4. 성공하면 `BT 000.0 / ET 000.0` 이 화면에 표시됩니다.
   - **기계 화면의 온도와 같은지** 확인
   - BT/ET가 서로 반대면 연결 설정 → "채널 서로 바꾸기"
   - 숫자가 10배 크거나 작으면 "값 나누기"를 1 또는 10으로
   - 몇 도 어긋나면 BT/ET 보정(°C)
5. 예열 중 온도가 움직이는지 보고, **투입 자동 감지**를 켜두면 생두 투입 시 타이머가 자동 시작됩니다.

## 안 될 때
| 증상 | 확인 |
|---|---|
| 포트 목록이 비어 있음 | 케이블(충전 전용 불가), 드라이버, 기계 전원, 장치관리자 COM 포트 |
| "포트 열기 실패" | Cropster/Artisan 등 **다른 프로그램이 포트를 점유** 중인지 종료 |
| 통신 실패 | 자동 탐색 로그 캡처 → 이 대화에 보내기 |
| 통신은 되는데 온도 못 찾음 | 로그 캡처 + 기계 조작부/라벨 사진 (통신 주소표 필요) |
| 터치스크린(PLC) 모델 | USB가 아니라 네트워크(IP) 통신일 수 있음 → 중계 프로그램 필요 |

연결 설정의 **"통신 로그(TX/RX) 표시"** 를 켜면 주고받는 신호가 로그에 찍힙니다.

## 첫 로스팅 때
- 앱은 **온도를 읽기만** 합니다. 기계를 제어하지 않으니 평소처럼 직접 조작하세요.
- 처음 한두 번은 기존 방식(눈·소리)과 **병행**하고, 이벤트 버튼으로 수동 기록도 같이 하세요.
- 로스팅 중에는 노트북 화면이 꺼지지 않게 설정하고, 전원을 연결해 두세요.
- 투입 온도·투입 시 화력·배기를 입력해 두면 진단과 다음 배치 제안이 정확해집니다.
- 끝나면 **배출 후 무게**와 컵핑 메모를 입력하고, 설정 탭에서 **JSON 백업**을 받아두세요.
